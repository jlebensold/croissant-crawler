About this index

Croissant is the MLCommons metadata format for ML datasets (JSON-LD on top of schema.org). Hugging Face, Kaggle, OpenML and Dataverse all publish it. This index crawls those platforms, keeps every version of every Croissant file, validates it, scores its metadata quality, enriches it with an LLM and links everything into a knowledge graph.

Pipeline

  1. Repos → links. Source adapters page through each platform's listing API and upsert Croissant URLs into a crawl frontier, with first-seen / last-seen timestamps and upstream revision markers.
  2. Fetch. Polite, rate-limited fetches (per-source Temporal task queues + per-host token buckets, Retry-After, circuit breakers). Unchanged upstream revisions are skipped; revisit intervals adapt to how often a dataset changes.
  3. Validate. JSON parse → Croissant shape → mlcroissant spec validation → a transparent 100-point quality rubric (tiers A–F).
  4. Croissant store. Immutable, content-addressed versions (SHA-256 of canonical JSON) in Postgres; exportable as JSON Lines.
  5. Index. Typesense full-text + facets + built-in sentence embeddings for semantic and hybrid search.
  6. LLM. Summaries, controlled-vocabulary tasks / modalities / domains, organisations, lineage and placeholder detection via OpenRouter, grounded against the source text and cached by content hash.
  7. Graph. Datasets linked to sources, organisations, licenses, tasks, modalities, domains, papers, lineage (DERIVED_FROM), cross-platform duplicates (SAME_AS) and embedding neighbours (SIMILAR_TO).

Quality score

Validity 25 · Descriptive metadata 30 · Distribution 20 · Structure 15 · Responsible AI 10. Documents with spec errors are capped at 49 and placed in tier F. Every score links to its per-check breakdown.

JSON API: /docs. Data export: croissant-crawler export. Graph export: /api/graph/export.
